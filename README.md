# UptimeHub

UptimeHub is a production-oriented cloud monitoring and status platform designed to monitor the availability and health of external services.

The project is built using a modern cloud-native architecture and demonstrates infrastructure automation, container orchestration, CI/CD, security, monitoring, and reliability practices.

## Architecture

The platform consists of:

- React / Next.js frontend
- FastAPI backend
- Python monitoring worker
- PostgreSQL database
- Redis
- Docker containers
- Kubernetes / AKS
- Azure Container Registry
- Azure Key Vault
- Terraform
- Azure DevOps pipelines
- Prometheus
- Grafana
- Azure Monitor
- Log Analytics

## Environments

- Development
- Production

## Repository Structure

- `application/` - application source code
- `infrastructure/` - Terraform infrastructure
- `kubernetes/` - Kubernetes manifests
- `helm/` - Helm charts
- `monitoring/` - Prometheus, Grafana, and alerts
- `pipelines/` - CI/CD pipeline definitions
- `scripts/` - automation scripts
- `tests/` - automated tests
- `docs/` - architecture, security, operations, and runbooks
